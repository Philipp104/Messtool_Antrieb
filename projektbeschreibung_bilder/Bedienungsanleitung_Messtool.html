Bedienungsanleitung – Messtool

Stadler – E-Engineering Version: 2026-07-23

01 Programmübersicht

Das Messtool ist eine Python-basierte Anwendung zur Verarbeitung und Analyse von Messdaten aus Excel- und CSV-Dateien. Das Programm berechnet Zeit- und Frequenzdaten, visualisiert Signale und ermöglicht erweiterte Filterung sowie Export-Funktionen. Alle Berechnungen erfolgen automatisch nach dem Import der Daten.

02 Hauptfenster – Eingabebereiche

Start Reihe / End Reihe

Definieren Sie den Zeilenbereich Ihrer Messdaten (z. B. 2–1000). Reihe 1 enthält typischerweise Header-Informationen und wird ignoriert. Die Startreihe sollte die erste Datenzeile sein. Gültige Eingaben: positive ganze Zahlen.

Beispiel Start Reihe = 2, End Reihe = 500 → importiert die Zeilen 2 bis 500.

Start Spalte / End Spalte

Wählen Sie den Bereich der Messkanäle aus. Spalten können als Buchstaben (A, B, C …) oder als Nummern (1, 2, 3 …) angegeben werden – das System konvertiert automatisch. Metadaten-Spalten wie SECTION, LOGDATA, Nb, Type, Date und Time werden automatisch ignoriert.

Samplefrequenz FS [Hz]

Abtastfrequenz in Hertz (Anzahl der Messwerte pro Sekunde). Diese Eingabe ist entscheidend für:

  • Zeitachse: dt = 1 / FS
  • FFT-Frequenzauflösung: df = FS / n
  • Filtervalidierung: Grenzfrequenzen müssen unter FS / 2 (Nyquist) liegen
Beispiel FS = 1000 Hz → dt = 0,001 s = 1 ms pro Messwert.
Automatische Erkennung Enthält die geladene Datei echte Zeitstempel, wird die tatsächliche Aufnahme-Samplefrequenz automatisch daraus berechnet (Median der Zeitabstände) und das Feld ist gesperrt – eine manuelle Eingabe würde sonst nicht mehr zur echten Aufnahme passen und alle Berechnungen (FFT, Filter, Zeitachse) verfälschen. Nur wenn die Datei keine echten Zeitstempel enthält, bleibt das Feld wie bisher frei editierbar.

Fenstertyp

  • Rechteck: Gleichmäßige Gewichtung aller Datenpunkte. Einfach, aber höhere Spektral-Leckage.
  • Hanning: Reduzierte Leckage durch geringere Randgewichtung. Besser für detaillierte Spektrumanalysen bei engen Frequenzbändern.

03 Dateiimport

Datei importieren (Button)

Klicken Sie auf „Datei importieren", um eine Excel- oder CSV-Datei auszuwählen. Das Programm:

  • Erkennt automatisch die Zeichenkodierung (UTF-8, Latin-1, Windows-1252 usw.)
  • Identifiziert den Spalten-Separator bei CSV (Komma, Semikolon, Tab, Leerzeichen)
  • Entfernt leere Zeilen und Spalten automatisch
  • Erkennt MultiIndex-Header bei Excel (Signalname in Reihe 1, Einheit in Reihe 2)
  • Zeigt Fortschritt mit Prozentsatz und Dateiname im Statusfenster an

Nach erfolgreichem Import werden die verfügbaren Spalten in der Signalliste angezeigt.

04 Datenverarbeitung

Verarbeitung starten (Button)

Nach dem Import klicken Sie auf „Verarbeitung starten". Das Programm berechnet automatisch:

  • Zeitachse (t): Lineares Array von 0 bis (n−1) · dt
  • Frequenzachse (f): FFT-Frequenzen von 0 bis FS / 2, Auflösung df = FS / n
  • FFT-Spektren: Amplitude und Phase aller ausgewählten Signale
  • Statistische Werte: Startzeit, Endzeit, Anzahl Samples, dt, df

Alle Schritte werden mit Zeitstempel im Statusbereich protokolliert. Bei Fehlern erscheint eine aussagekräftige Fehlermeldung.

05 Ausgabefelder

Nach erfolgreicher Verarbeitung werden folgende Werte automatisch angezeigt:

Startzeit / Endzeit

Zeitliche Grenzen der Messdaten. Startzeit = immer 0 s; Endzeit = (n−1) · dt. Schreibgeschützt, nur zur Information.

Samples (n)

Gesamtzahl der Messwerte im definierten Bereich. Mehr Samples = bessere Frequenzauflösung (df = FS / n).

dt [s]

Zeitschritt zwischen zwei Messwerten. dt = 1 / FS  →  FS = 1000 Hz ergibt dt = 0,001 s.

df [Hz]

Frequenzauflösung des Spektrums. df = FS / n  →  FS = 1000 Hz, n = 10.000 ergibt df = 0,1 Hz.

06 Signalauswahl & Visualisierung

Einzelsignale auswählen

Wählen Sie ein Signal durch Einfachklick aus der Liste. Das Analyse-Ergebnisse-Fenster öffnet sich automatisch.

Mehrere Signale auswählen

Verwenden Sie Strg+Klick, um mehrere Signale zu markieren. Alle markierten Signale werden gemeinsam im Analyse-Ergebnisse-Fenster dargestellt – jedes in einer eigenen Farbe (Seaborn-Palette).

Gruppenanalyse

Über den Gruppen-Reiter können Signale zu Gruppen zusammengefasst und gemeinsam analysiert werden. Jede Gruppe erhält einen eigenen Subplot mit allen überlagerten Signalen.

07 Analyse-Ergebnisse-Fenster

Das Analyse-Ergebnisse-Fenster öffnet sich nach der Signalauswahl und zeigt alle Analysen in einem eigenen Fenster. Der Plot passt sich automatisch an die aktuelle Fenstergröße an.

Analyse-Typen (Signal-Menü)

Über das Menü „Signal" oben links stehen folgende Analysearten zur Verfügung:

  • Signal: Zeitverlauf des Original-Signals (und optional des gefilterten Signals)
  • AVG: Zeitverlauf mit eingeblendeter Durchschnittslinie (Mittelwert)
  • RMS: Zeitverlauf mit eingeblendeter RMS-Linie (Effektivwert)
  • Differential: Zeitverlauf + erste Ableitung des Signals (d/dt)
  • Integral: Zeitverlauf + Integral über die Zeit (kumulierte Summe)
  • FFT: Zeitverlauf + Amplitudenspektrum + Phasenspektrum
  • Statistik: Zeitverlauf mit Mittelwert und ±1σ-Band (Standardabweichung)

Bei aktivierter Filterung werden die gefilterten Kurven in allen relevanten Subplots zusätzlich dargestellt.

Synchroner Zoom

Die Checkboxen „Synchroner Zoom" synchronisieren den Scroll-Zoom auf der Zeitachse über mehrere Subplots hinweg. Bei mehreren Plot-Typen kann die Synchronisierung pro Gruppe separat aktiviert oder deaktiviert werden.

Plot-Bedienung (Maus)

  • Linksklick: Zoom bzw. Cursor setzen (siehe unten, abhängig vom gewählten Cursor-Modus)
  • Rechtsklick halten + ziehen: Plot verschieben (Pan)
  • Mausrad über einem Subplot: zoomt diesen Subplot (bzw. alle synchronisierten bei aktivem synchronem Zoom)
  • Mausrad über freier Fläche neben den Plots: scrollt das Fenster

Cursor-Modus: „Einer"

Zwei-Klick-Bereichsauswahl: der erste Klick setzt den Startpunkt, der zweite Klick den Endpunkt. Das Programm:

  • Zeigt eine vertikale Markierungslinie mit eingekreister Nummer (1/2) je Klick
  • Zoomt nach dem zweiten Klick automatisch in den gewählten Zeitbereich
  • Rendert alle synchronisierten Subplots auf den selektierten Bereich neu
  • Bei Gruppen-Plots erscheinen die Messwerte aller Signale zusätzlich als Karte im Seitenpanel „Gesetzte Cursor" (siehe unten) – nach dem Zoomen verschwinden Markierung und Karte automatisch wieder, da die Auswahl damit abgeschlossen ist

Cursor-Modus: „Mehrere"

Jeder Linksklick setzt einen zusätzlichen, dauerhaft angezeigten Cursor (fortlaufend durchnummeriert), ohne zu zoomen. Bei Gruppen-Plots erscheint pro Cursor eine eigene Karte im Seitenpanel „Gesetzte Cursor" mit den Werten aller Signale an dieser Stelle.

Gesetzte Cursor (Seitenpanel) Bei Gruppen-Plots (mehrere Signale je Subplot) ist im Plot selbst kein Platz für eine Wertetabelle – stattdessen öffnet sich neben dem Plot ein eigener, in der Breite verschiebbarer Bereich mit einer Karte pro gesetztem Cursor (Signalname, x-/y-Werte). Das Panel erscheint automatisch beim ersten gesetzten Cursor und verschwindet wieder, sobald keine Cursor mehr gesetzt sind (Zurücksetzen, alle Cursor aufgehoben, oder – im Modus „Einer" – nach dem Reinzoomen beim zweiten Klick).

Bei einfachen Plots (ein Signal je Subplot) wird der Messwert stattdessen direkt als Annotation im Plot angezeigt.

Zurücksetzen / Zurück / Vor (Buttons)

  • Zurücksetzen: stellt die ursprüngliche Zoom-Ansicht wieder her und löscht alle Cursor und Bereichsauswahlen. X- und Y-Achsenlimits werden exakt auf die beim Öffnen des Fensters gültigen Werte zurückgesetzt.
  • ◀ Zurück / ▶ Vor: navigieren durch den Zoom-/Cursor-Verlauf (wie „Undo"/„Redo"), ersetzen die frühere Matplotlib-Toolbar.
  • Export: exportiert den aktuell sichtbaren Ausschnitt.

08 Gruppenbildung & Analyse

Gruppen erstellen

Signale können in Gruppen organisiert werden, um verschiedene Aspekte der Messdaten getrennt zu analysieren. Beispiele:

  • Gruppe 1: Temperatur-Sensoren
  • Gruppe 2: Druck-Sensoren
  • Gruppe 3: Beschleunigungs-Sensoren

Signale zu Gruppen hinzufügen

Wählen Sie Signale aus der Liste aus und ordnen Sie sie einer Gruppe zu. Die Gruppierung wird für die aktuelle Sitzung gespeichert. Bei erneutem Import müssen die Gruppen neu definiert werden.

Gruppen auswählen & löschen

Ein Klick auf eine Gruppe markiert sie (farblich hervorgehoben blauer Hintergrund) – ein weiterer Klick hebt die Markierung wieder auf. Über den Button „Gruppe(n) löschen" werden alle aktuell markierten Gruppen nach Bestätigung entfernt.

Gruppenanalyse

Für jede Gruppe stehen alle Analyse-Typen aus Kapitel 7 zur Verfügung. Pro Gruppe wird ein eigener Subplot erstellt, in dem alle Signale der Gruppe überlagert dargestellt werden.

09 Filterung

Filter aktivieren

Aktivieren Sie das Kontrollkästchen „Gefiltert verwenden (Anzeige & Export)". Das Programm validiert automatisch die Filterparameter.

Filtertyp

  • Kein Filter: Keine Filterung – Originaldaten werden verwendet.
  • Tiefpass: Lässt niedrige Frequenzen durch, dämpft hohe. Geeignet zum Entfernen von Hochfrequenzrauschen.
  • Hochpass: Lässt hohe Frequenzen durch, dämpft niedrige. Geeignet zum Entfernen von Gleichanteilen oder Drifts.
  • Bandpass: Lässt nur Frequenzen in einem bestimmten Bereich durch. Geeignet zur Isolation spezifischer Frequenzbänder.

Filtercharakteristik

  • Butterworth: Flacher Durchlassbereich, sanfter Übergang. Beste Wahl für allgemeine Anwendungen.
  • Bessel: Minimal verzerrte Phase. Beste Wahl, wenn die Phasenlage erhalten bleiben soll.
  • Chebyshev I: Steilerer Übergang, leichte Welligkeit im Durchlassbereich.
  • Elliptic: Steilster Übergang, höchste Welligkeit. Nur bei sehr steilen Flankenanforderungen.

Grenzfrequenzen

  • Tiefpass / Hochpass: Eine Grenzfrequenz eingeben (kleiner als FS / 2).
  • Bandpass: F1 und F2 eingeben, wobei F1 < F2 und beide kleiner als FS / 2.
Beispiel Bandpass F1 = 10 Hz, F2 = 100 Hz → nur Frequenzen zwischen 10 und 100 Hz werden durchgelassen.

Filterordnung

  • Niedrige Ordnung (z. B. 2): Sanfterer Übergang, geringere Rechenzeit.
  • Hohe Ordnung (z. B. 8): Steilerer Übergang, mehr Rechenzeit.
  • Bandpass: Nutzt automatisch Kaskaden-Sektionen (SOS) für höhere numerische Stabilität.

Validierung

Das Programm prüft vor der Anwendung automatisch:

  • ✓  Grenzfrequenzen unter der Nyquist-Frequenz (FS / 2)?
  • ✓  Bei Bandpass: F1 < F2?
  • ✓  Grenzfrequenzen > 0 Hz?
  • ✓  Alle Eingaben numerisch gültig?
Achtung Bei ungültigen Parametern wird eine Warnung angezeigt (z. B. „Grenzfrequenz 600 Hz liegt über Nyquist 500 Hz") und der Filter nicht angewendet. Die Originaldaten bleiben unverändert.

10 Export

Export (Button im Analyse-Ergebnisse-Fenster)

Jeder Analyse-Tab (Kapitel 7: Signal, AVG, RMS, FFT, Differential, Integral, Statistik) hat neben „Zurücksetzen" einen eigenen „Export"-Button. Ein Klick fragt einen Zielordner ab und speichert jedes im Tab angezeigte Signal als eigene Excel-Datei dort hinein.

Ausgabedateien

  • Excel-Workbook (.xlsx): Pro Signal ein separates Sheet
  • Info-Block: Metadaten und Filterparameter (Filtertyp, Grenzfrequenzen, dt, df, Zeitstempel)
  • Datenblock:
    • Time: Zeitachse [s]
    • Original: Originalsignaldaten
    • Gefiltert: Gefilterte Daten (falls aktiv)
    • Frequenz: FFT-Frequenzachse [Hz]
    • Amplitude: FFT-Amplitude (Magnitude)
    • Phase: FFT-Phase [° oder rad]

Optionale Zusatzdaten

  • Ableitungen & Integrale: Werden exportiert, wenn in den Overlays ausgewählt.
  • Summary-Tab: Zusammenfassung aller Signale (Frequenzauflösung, Filtereinstellungen).
  • PNG-Plots: Hochauflösende Plots im Ordner plots/ (Zeitplot, Frequenz-Plot, Übersichts-Plot).

Speicherpfad

Standardmäßig im Arbeitsverzeichnis unter Messtool_Export_[YYYYMMDD_HHMMSS].xlsx. Über „Pfad anzeigen" kann der Speicherpfad eingesehen und geändert werden.

Export-Optionen

  • Einzel-/Mehrfachsignal-Export: Im Analyse-Tab werden alle dort dargestellten Signale beim Klick auf „Export" gemeinsam exportiert – jedes als eigene Datei.
  • Gruppierter Export: Bei Gruppenanalyse (Kapitel 8) exportiert derselbe Button alle Signale aller angezeigten Gruppen.
  • Mehrfachdatei-Modus: Signale aus unterschiedlichen Dateien (Kapitel 13) können gemeinsam ausgewählt und im selben Vorgang exportiert werden.

11 Zusätzliche Funktionen

Pfad anzeigen (Button)

Öffnet ein Fenster mit Import-Pfad, Export-Verzeichnis, Plots-Verzeichnis und Dateigrößen. Verzeichnisse können direkt im Explorer geöffnet werden.

Reset wählen (Button)

  • Komplett zurücksetzen: Löscht alle Eingaben, Daten, Ergebnisse, Gruppen und Filtereinstellungen. Das Fenster wird in den Initialzustand versetzt.
  • Nur Eingabefelder zurücksetzen: Behält importierte Daten, setzt jedoch Reihen, Spalten und FS auf Standard zurück. Filtereinstellungen bleiben erhalten.

12 Wichtige Hinweise

Nyquist-Frequenz

Die maximal korrekt erfassbare Frequenz beträgt FS / 2. Alle Filtergrenzfrequenzen müssen darunter liegen.

Beispiel FS = 1000 Hz → maximale Grenzfrequenz = 500 Hz.

Bandpass-Filter

F1 (untere Grenze) muss kleiner als F2 (obere Grenze) sein. Nur Frequenzen zwischen F1 und F2 werden durchgelassen.

Minimale Datenpunkte

Mindestens 2 Messwerte erforderlich. Für aussagekräftige FFT-Ergebnisse werden 256–1024 Punkte empfohlen.

Unterstützte Dateiformate

  • Excel: .xlsx (bevorzugt), .xls
  • CSV: .csv mit automatischer Separator- und Encoding-Erkennung
  • MultiIndex-Header werden automatisch erkannt

Performance bei großen Datensätzen

Bei mehr als 100.000 Datenpunkten kann die Verarbeitung länger dauern. Die Berechnung erfolgt im Hintergrund mit Fortschrittsanzeige.

Meldungen & Hinweise

Status-, Warn- und Fehlermeldungen erscheinen als kurze Hinweisfenster oben rechts über dem jeweiligen Fenster und verschwinden nach einigen Sekunden von selbst – ein Klick auf die Meldung schließt sie sofort. Ein Bestätigen mit „OK" ist dafür nicht mehr nötig. Erscheinen mehrere Meldungen gleichzeitig, stapeln sie sich untereinander. Lediglich echte Ja/Nein-Rückfragen (z. B. beim Löschen einer Signalgruppe) müssen weiterhin aktiv bestätigt werden.

13 Mehrfachdatei-Import (Batch)

Mehrere Dateien auswählen

Beim Klick auf „Datei importieren" öffnet sich zunächst der normale Dateidialog. Danach erscheint ein Sammelfenster, in dem über „Mehr Dateien" beliebig viele weitere Excel-/CSV-/DWS-Dateien hinzugefügt werden können. Mit „Fertig" wird der Import abgeschlossen – bei genau einer Datei läuft alles wie gewohnt weiter (Kapitel 2–5), ab zwei Dateien öffnet sich das Mehrfachdatei-Panel.

Schritt 1 – Globale Einstellungen

Der Fenstertyp wird hier einmal gemeinsam für alle ausgewählten Dateien festgelegt. Die Samplefrequenz gibt es hier nicht mehr global – jede Datei erkennt bzw. benötigt ihre eigene (siehe Schritt 2).

Checkbox „Alle Dateien komplett reinladen" Standardmäßig angehakt. Ist sie aktiv, wird Schritt 2 (die einzelnen Datei-Tabs) beim Klick auf „Weiter" übersprungen – alle Dateien werden sofort mit „Ganze Datei verwenden" verarbeitet. Nach Abschluss erscheint eine Meldung mit der pro Datei tatsächlich verwendeten Samplefrequenz (siehe unten), da die Datei-Tabs dafür ja nicht einzeln durchgesehen werden. Zum manuellen Anpassen pro Datei (Zeilen-/Spaltenbereich) einfach abhaken.

Schritt 2 – Datei-Tabs

Jede Datei bekommt einen eigenen, farbig markierten Tab mit:

  • Sheet-Auswahl (bei Excel-Dateien)
  • Start-/End-Zeile und -Spalte (oder „Ganze Datei verwenden")
  • einem eigenen Samplefrequenz-Feld für diese Datei – enthält die Datei echte Zeitstempel, wird die reale Aufnahme-Samplefrequenz automatisch erkannt und das Feld gesperrt; sonst bleibt es editierbar (Standardwert als Vorschlag)
  • nach dem Verarbeiten: den eigenen Ausgabewerten dieser Datei (Startzeit, Endzeit, Samples, dt, df)

Über „Verarbeiten" läuft jede Datei unabhängig durch dieselbe Pipeline wie beim Einzelimport, mit ihrer eigenen Samplefrequenz. Unterschiedliche Spaltenanzahl oder Dauer zwischen den Dateien ist kein Problem, da nichts zeitlich zusammengeführt wird.

Automatisches Speichern pro Datei

Ist unter „2. Datenverarbeitung" eine Speicher-Option gewählt, werden Plots und Spektren automatisch für jede Datei einzeln in einen eigenen Unterordner spektren/<Dateiname>/ geschrieben.

Gemeinsame Signalauswahl (Signal-Pool)

Nach der Verarbeitung aller Dateien öffnet sich ein Signalauswahl-Fenster mit den Signalen aller Dateien zusammen. Signale können dateiübergreifend gemeinsam ausgewählt und analysiert werden (AVG, RMS, FFT, Differential, Integral, Statistik) – jedes Signal behält dabei seine eigene Zeitachse und, falls vorhanden, seine eigenen echten Zeitstempel (Uhrzeit-Achse, Kapitel 7).

Namenskollisionen Tragen zwei Dateien ein Signal mit demselben Namen (z. B. „Kanal1"), wird der Name automatisch um den Dateinamen ergänzt (Kanal1 (Datei2)), damit beide eindeutig auswählbar bleiben.

Zurück zu Schritt 1

Schließen Sie das Signalauswahl-Fenster oder klicken Sie auf „Eingaben zurücksetzen", gelangen Sie zurück zu Schritt 1 (Fenstertyp) – die bereits geladenen Dateien bleiben dabei erhalten, sodass direkt erneut verarbeitet werden kann. „Komplett zurücksetzen" verwirft dagegen auch die geladenen Dateien und beendet den Mehrfachdatei-Modus.
